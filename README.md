# Security Portfolio — 임베디드·IoT 취약점 분석

차량 소프트웨어(IVI, AAOS) 경력을 바탕으로 임베디드/IoT 보안 분석을 연습하며 정리하는 저장소입니다.
모든 분석은 **공개된 연습용 취약 대상이나 본인이 만든 앱**에만 수행하며, 실제 서비스/기기는 대상으로 하지 않습니다.

## 배경
- 자동차 IVI(Genesis·Hyundai) 소프트웨어 엔지니어 2년 — 인증·권한·디지털키 흐름 테스트, C/C++·Qt 코드 리뷰, 로그 분석
- 지금은 같은 임베디드 도메인을 **공격자 관점의 취약점 분석**으로 확장 중

공식 배포처에서 대상을 받아 동일하게 재현할 수 있습니다.
